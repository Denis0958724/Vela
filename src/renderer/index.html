Основне

          
Загальні

          
          
Тут створюються нові проєкти. Наявну папку можна підключити через «Відкрити папку як проєкт».

          
          
Діють у всіх чатах. Зміни застосовуються з наступного повідомлення.

          
          

            
          

        


        

          
Зовнішній вигляд

          
Тема

          
Основна тема: глибокий індиго з лавандовим акцентом. Світла й нічна залишаються на вибір.

          

            
            
            
          

          
Тема застосовується одразу і зберігається без перезапуску.

        


        

          
Безпека

          
Дозволи

          
Інтернет і керування комп'ютером вимкнені за замовчуванням. У режимі «питати» кожен виклик все одно потребує окремого підтвердження, крім автономного керування ПК.

          
          
          
          
run_shell входить у керування файлами. Керування комп'ютером відкриває саме графічні дії, але не робить застосунок пісочницею для ОС.

          

            
          

        


        

          
Підключення

          
Free LLM API

          
Один OpenAI-сумісний шлюз для всіх моделей. Ключ зберігається в системному сховищі Windows і не покидає цей ПК.

          

            
            
            
Перевірка ще не запускалась.

            

              
              
            

          

          
Моделі шлюзу з'являться у вкладці «Моделі» та в меню моделі в чаті. Окремого пункту в шапці чату немає.

        


        

          
Каталог

          
Моделі

          
Модель обирається внизу чату. Тут видно ліміти й можна перевірити, які моделі відповідають.
